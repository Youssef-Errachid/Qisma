# Button

Buttons: primary for the one main action per view, secondary and outline beside it, ghost for low-emphasis links, danger for destructive actions.

Hover darkens the fill (`brand-600-hover`) and lifts a shadow; a trailing arrow slides 3px. Pressed moves 1px down. Minimum height 44px. Use `<button>` for actions and `<a class="q-btn">` for navigation. One primary per region.
