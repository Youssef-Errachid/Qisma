# GroupCard

Clickable group card with a colored top rule, initials tile, meta, the user's balance and an avatar stack.

The whole card is one link: on hover it lifts 2px with `shadow-hover` and `border-hover`; the avatar stack fans out and the arrow slides. Top rule cycles `accent-green`, `accent-orange`, `accent-purple`. Archived groups use `q-card--archived`, no lift, and a read-only badge.
