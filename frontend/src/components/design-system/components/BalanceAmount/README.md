# BalanceAmount

How a balance is written: words plus amount, on a matching tint.

Owed: `owed` on `owed-soft`, label “You're owed”. Owe: `owe` on `owe-soft` (peach), label “You owe” and NO minus sign. Settled: `ink-muted`. Amounts use Space Grotesk and tabular figures, currency code after the number.
